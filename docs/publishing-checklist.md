# 公開前檢查清單

- [ ] 確認每個第三方素材的來源 URL、作者、原始檔名與版本。
- [ ] 記錄授權名稱、授權條款連結、查證日期與證據。
- [ ] 分別確認原始模型及衍生檔案是否允許公開再散布，並遵守署名、相同方式分享等適用條件。
- [ ] 不明或不允許公開的檔案留在 unreviewed/ 或 private/，只提交連結、授權資訊與筆記。
- [ ] 照片確認擁有公開權利，移除不必要的個資、位置資訊與敏感背景。
- [ ] 檢查 git status、git diff --cached --name-status 與 git diff --cached；確認沒有模型誤傳、私人照片、憑證或暫存檔。
- [ ] 確認試印／試裝結果有實際依據，尚未執行的項目明確標記。
- [ ] 推送後核對 main 的 commit 與檔案內容。

.gitignore 只是防呆，不能判斷授權，也不會自動停止追蹤已提交的檔案。避免對未確認素材使用 git add -f。
