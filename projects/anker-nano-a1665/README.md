# Anker Nano A1665 V2 簡化保護殼

## 目前目標

修改原始 Skadis A1665 3MF：
1. 移除兩個背面掛鉤。
2. 將 U 型框架兩側延伸至高於行動電源機身。
3. 暫不加入第四邊與門栓。

## 目前狀態

本階段只建立 Repo 與文件，尚未開始 CAD 修改、匯出、試印或試裝。
原始模型檔案、來源 URL、作者及授權尚未提供。機身尺寸、延伸高度、間隙與列印參數尚待確認，不先設定數值。
