# Anker Nano A1665 V2 簡化保護殼

## 目前目標

修改原始 Skadis A1665 3MF：
1. 移除兩個背面掛鉤。
2. 將 U 型框架兩側延伸至高於行動電源機身。
3. 暫不加入第四邊與門栓。

## 目前狀態

2026-10-08 已依使用者正式授權完成 V2 CAD／mesh 修改、STL 與 A1 mini PETG 3MF 匯出及實際切片。使用者已回報送出首次列印；列印完成與試裝結果待確認。

外形寬 76.4 × 厚 13.4 × 高 105.7 mm；承托面至兩側最高端 103.5 mm。以參考機身長 102 mm 計算，高出量為 1.5 mm。保留原側槽與底部；去除掛鉤及背面掛鉤承梁，頂部完全開放，沒有第四邊、門栓或覆板。

完整修改、驗證、列印設定與限制見 [V2 紀錄](tests/2026-10-08-v02.md)。成品僅存於本機被忽略的目錄；原檔內嵌 MakerWorld Exclusive License，尚未取得 GitHub 再散布許可。
