# V01 CAD 與組裝

本機可編輯檔：`unreviewed/tethered-plug-protector-v01.blend`（列印排盤）、`unreviewed/v01-assembly.blend`（組裝示意）。建模程序：`unreviewed/build_v01.py`，使用 Blender 5.1.2 內建幾何工具。沒有新增 repo 套件依賴。

## 設計理由與尺寸

參考蓋外形原為 17.2 × 19.5 × 9.9 mm；新增軸耳後 X 向總寬 25.4 mm。原側扣線夾外形約 14.997 × 10 × 10 mm；新增軸耳後 X 向總寬約 23.298 mm。以上是模型座標量測，不是實物配合測試。

圓角連桿總長 31.6 mm、孔距 24 mm、寬 7.6 mm、厚 2.4 mm，三段展開孔距合計 72 mm。轉孔直徑 3.4 mm、軸身直徑 3.0 mm，設計單邊徑向間隙 0.2 mm。兩片疊合厚 4.8 mm；肩軸可用長 5.6 mm，總軸向餘量 0.8 mm。這些是 V01 設計值，尚未以實際線材校準。

固定帽外徑 6 mm、厚 1.8 mm、內孔直徑 2.4 mm，入口倒角；軸端為直徑 2.55→2.4 mm 的錐形壓入段。固定帽靠過盈留住，尚未驗證保持力。渲染圖用深色區分軸銷，交付切片為單色 PLA，不要求換色。

## 組裝順序

1. 先用備用軸銷與固定帽試壓配合；固定帽太鬆、無法壓入，或軸身出現白化／裂紋時，記錄狀況並調整尺寸，不強壓主要零件。
2. 連接順序為「保護蓋耳 → 連桿 1 → 連桿 2 → 連桿 3 → 線夾耳」。連桿上下交錯，蓋耳、連桿 2、線夾耳在下層；連桿 1、3 在上層。
3. 四處各穿一根肩軸銷，從另一側壓上固定帽至肩部；確認各節能轉動、有軸向餘量且固定帽不自行脫落。剩餘一組為備品。
4. 在拔離電源的插頭上試裝蓋子，再將線夾由電線側面扣入；調整線夾沿線的位置，確認蓋子能完全裝入與取下，不拉扯連桿或電線。

只有完成試裝後才能判定適配；不宣稱電氣絕緣、防水、兒童安全或抗踩認證。此件用途是未插電時的插腳收納保護，插入插座前必須取下蓋子。
